# 🛒 Superstore Sales Analysis

## Project Overview
SQL analysis of a US retail superstore dataset containing 9,994 orders
across 3 product categories and 4 regions, to uncover sales trends,
profit drivers, and regional performance.

## Business Questions Answered
- Which region generates the most profit?
- What are the top 5 customers by revenue?
- Which product sub-category has the worst profit margin?
- How does shipping mode affect sales volume?

## Tools Used

## Dataset
Superstore Dataset (https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
— 9,994 rows | 21 columns | 2014–2017 US retail orders
